# 画像ぼかしアプリ

写真・スクリーンショットの一部を、ぼかし/モザイク/塗りつぶしで隠すブラウザアプリです。
画像はすべてブラウザの中だけで処理され、外部には一切送信されません。

このREADMEでは、**Cloudflare Pages**(Cloudflare社が無料で提供している「Webページを世界中に公開できるサービス」)への公開手順を説明します。

---

## 公開前の確認: 外部通信は一切ありません

`public`フォルダの中身(このアプリが実際に配信するファイルすべて)を確認した結果、以下のとおり**外部への通信は一切ありません**。

- `fetch`・`XMLHttpRequest`・`WebSocket`など、通信を行うコードは1つも使われていません
- 外部サイトのCDN(他社が配信しているライブラリ)の読み込みもありません
- 解析ツール・アクセス解析(Googleアナリティクスなど)も一切入っていません
- `index.html`・`style.css`が読み込むファイルは、すべて同じフォルダ内の相対パス(`style.css`、`js/main.js`など)だけで、外部サイトのURLは1つも含まれていません

実際に`public`フォルダをローカルのサーバーで動かし、ブラウザの「どの通信が発生したか」を記録する機能で確認したところ、読み込まれたのは自分自身のファイル(`index.html`・`style.css`・`js/`以下の6つのファイル)だけで、それ以外の通信は一切発生しませんでした。CLAUDE.mdの「画像は外部に送信しない」という条件を満たしています。

---

## 公開用フォルダについて

`public` フォルダに、公開に必要なファイルだけをまとめました。

```
public/
├── index.html
├── style.css
└── js/
    ├── image-loader.js
    ├── region-store.js
    ├── effects.js
    ├── canvas-view.js
    ├── exporter.js
    └── main.js
```

`test-images`(動作確認用の写真)や`CLAUDE.md`(開発時の方針メモ)は、公開する必要がないため含めていません。

**注意**: `public`フォルダは、元のファイルを**コピー**したものです。今後アプリのコードを直接修正した場合、`public`フォルダの中身は自動では更新されません。修正のたびに、同じ内容を`public`フォルダにもコピーし直す必要があります(次にお手伝いする際は、この作業もあわせて行います)。

## Cloudflare Pagesとは

**Cloudflare Pages**は、HTML/CSS/JavaScriptだけでできたWebサイトを、無料で世界中に公開できるサービスです。このアプリのように「サーバー不要」で動くサイトにちょうど向いています。

公開すると、`https://(好きな名前).pages.dev` のようなURLが発行され、誰でもそのURLからアプリを使えるようになります。

---

## 公開の手順(はじめての方向け)

Cloudflareのアカウントさえあれば、`public`フォルダをドラッグ&ドロップするだけで公開できます。GitHubなどの他のサービスは不要です。

### 1. Cloudflareのアカウントを作る(すでにお持ちの場合は不要)

1. [https://dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) にアクセスする
2. メールアドレスとパスワードを入力してアカウントを作成する(無料)

### 2. Cloudflareの管理画面(ダッシュボード)を開く

1. [https://dash.cloudflare.com](https://dash.cloudflare.com) にログインする
2. 左側のメニューから「**Workers & Pages**」を選ぶ

### 3. 新しいPagesプロジェクトを作る

1. 「作成する(Create)」ボタンを押す
2. 「Pages」タブを選ぶ
3. 「**Upload assets**」(アセットをアップロード、という意味です。「アセット」= 画像やファイルなどの素材のことです)を選ぶ
4. プロジェクト名を入力する(例: `blur-app`。これが公開URLの一部になります → `https://blur-app.pages.dev`)

### 4. `public`フォルダをアップロードする

1. 画面の指示に従い、このプロジェクトの`public`フォルダ**の中身**を選択してアップロードする
   - 注意: `public`フォルダそのものではなく、**`public`フォルダの中にある`index.html`や`style.css`などのファイル・フォルダをまとめて選ぶ**のがポイントです(フォルダごとドラッグ&ドロップできる場合はそれでも構いません)
2. アップロードが終わると、自動的に公開処理(デプロイ)が始まります

### 5. 公開されたURLを確認する

1. デプロイが完了すると、`https://(プロジェクト名).pages.dev` という形のURLが表示されます
2. そのURLにアクセスして、アプリが正しく開くか確認してください

## 公開後、内容を更新したいとき

このアプリは現在GitHubなどの「リポジトリ」(ファイルの変更履歴を管理する仕組み)を使っていないため、更新のたびに以下の作業が必要です。

1. アプリのコードを修正する
2. 修正した内容を、あらためて`public`フォルダにコピーする
3. Cloudflareのダッシュボードで、そのプロジェクトを開き、「新しいデプロイを作成」→ `public`フォルダを再アップロードする

もし今後、修正のたびに毎回アップロードし直すのが面倒に感じたら、GitHubなどと連携して「コードを更新すると自動で公開される」仕組みに変更することもできます。その場合はあらためてご相談ください。

---

## 補足: 公開後の注意点

- 発行されたURLを知っている人は誰でもこのアプリを使えます。ただし、アプリ自体が画像を外部に送信しない作りなので、**利用者がアップロードした画像がCloudflareや第三者に渡ることはありません**(すべてその人のブラウザの中だけで処理されます)
- 独自ドメイン(例: `blur.あなたのサイト.com`)を使いたい場合も、Cloudflareのダッシュボードから設定できます。ご希望があれば手順をご案内します
